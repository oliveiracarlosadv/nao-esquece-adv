# Pedido 02 — Backup de código e Markdown

**Data:** 09/11/2026

## Texto integral

> sempre faça backup dos códigos, atualize o markdown, tudo na pasta.

## Como foi atendido

- Script `scripts/backup.sh` gera um `.zip` datado de todo o código-fonte em `BACKUPS/` (sem `node_modules`).
- Um backup é gerado ao final de cada entrega.
- `CHANGELOG.md` e `PEDIDOS/README.md` são atualizados a cada pedido.
