# Pedido 08 — Botão "Salvar na área de trabalho" = instalar o web app

**Data:** 10/11/2026

## Texto integral

> o botão salvar na area de trabalho não é para salvar na area de trabalho, mas sim para instalar o app como web app nos desktops e nos dispositivos moveis como atalho web app. Entrendeu?

## Como foi atendido

- O botão **"Salvar na área de trabalho"** agora instala o app (PWA) como atalho:
  - Chrome/Edge (Windows, Mac, Linux) e Android: abre a janela de instalação do navegador.
  - iPhone/iPad (Safari): mostra o passo a passo "Compartilhar → Adicionar à Tela de Início".
  - Safari no Mac: mostra "Arquivo → Adicionar ao Dock".
  - Se o app já estiver instalado, o botão informa isso.
- O botão fica no topo de todas as telas e na página inicial.
- A antiga tela "Área de trabalho" (consultas salvas, painéis, processos fixados, favoritos) foi renomeada para **"Meus painéis"**, e o botão do painel que salvava filtros virou **"Salvar consulta"**.
